このツールについて
日経先物を取り巻く複数の材料を並べ、相場環境を観察するための個人制作ツールです。売買判断や売買推奨を行うものではありません。

① 入力する項目
・日経先物騰落率：前日終値比の変化率を-10〜+10%で入力
・ダウ騰落率：前日比の変化率を-10〜+10%で入力
・VIX（恐怖指数）：確認した値を0〜60で入力（18未満=強気、25超=弱気）
・米10年債利回り：確認した値を0〜10%で入力
・ドル円、原油：背景情報として入力。ドル円と原油は環境スコアに直接加算しません
・MA配列：チャートでMA20・MA50・MA100を確認し、上昇／下降／混在を手動選択

② スコアの見方
スコアはMA配列、VIX、ダウ騰落率、日経先物騰落率、米10年債利回りを単純化して合算した参考値です。閾値は仮設定で、統計的な予測精度が検証されたものではありません。スコアだけで相場の方向が決まるわけではありません。

③ 日々の記録
「日々の記録」で入力内容とメモを保存できます。翌営業日の日経騰落率は後日入力し、CSVに書き出してご自身で振り返れます。記録はこのブラウザ内に保存されます。ブラウザのデータ削除や端末変更に備えて、定期的にCSVを保存してください。

④ ご注意
このページは手動入力のみで、リアルタイムデータ取得や価格データとの自動連携はありません。初期値は入力例であり、現在の市場データを示していません。表示は将来の値動きや利益を保証せず、実際の売買判断に使用しないでください。
